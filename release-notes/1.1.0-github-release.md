# pmsims 1.1.0

`pmsims` 1.1.0 introduces a new learning-curve search engine, which is now the
default.

## Highlights

- The learning-curve engine (`method = "curve"`) fits a monotone learning curve
  to every replicate simulated so far, and places each new batch where the
  curve crosses the target. It reports the minimum sample size with a
  bootstrap interval and a shape-free cross-check. The `mlpwr` engine is still
  available with `method = "mlpwr"`.
- `plot()` shows the learning curve, the target and the minimum sample size
  with its interval. With `live_plot = TRUE`, the plot is redrawn after each
  batch during the search.
- Every result has a `status` (`"ok"`, `"not_verified"`, `"not_bracketed"`,
  `"unreachable"`, `"replicates_failed"`). Before it is returned, the minimum
  sample size is simulated again with fresh replicates.
- Each replicate has its own random-number stream, so results are reproducible
  with `set.seed()` and are the same for any number of `cores`.
- Metrics and data generation are faster. A binary `glm` search takes about two
  thirds of the time it did in 1.0.0, and a Cox search about a quarter.

## Corrections

Several corrections were made to the simulation, so sample sizes may differ
from those given by 1.0.0. These include:

- Correlated predictors now have the requested pairwise correlation.
- Replicates whose metric is not finite count as failed replicates.
- Metrics where smaller is better (`"calibration_in_the_large"`,
  `"brier_score"`, `"ibs"`) can no longer be used as search targets.
- The concordance fallback in `survival_auc` has been corrected.

## Interface changes

- `min_n` and `perf_n` are `NA` when no sample size is found (they were a
  character message); see `status` and `status_message`.
- The `simulate_*()` wrappers no longer suppress warnings.
- `metric_2_at_n` is the mean over 10 replicates at `min_n`.
- With `method = "mlpwr"`, `n_reps_total` is raised to 2000 for `"lm"`,
  `"glm"` and `"coxph"` models with at most 10 signal parameters
  (`auto_n_reps_total = FALSE` turns this off).

## Install

```r
install.packages("pmsims")
```
