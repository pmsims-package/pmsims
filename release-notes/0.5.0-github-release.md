# pmsims 0.5.0

`pmsims` 0.5.0 is the initial public release of the package. It provides a
simulation-based framework for minimum sample size estimation in prediction
model development, with support for continuous, binary, and time-to-event
outcomes.

## Highlights

- Wrapper workflows for common use cases via `simulate_binary()`,
  `simulate_continuous()`, and `simulate_survival()`.
- Support for both mean-based and assurance-based criteria when identifying the
  minimum sample size that meets a target level of predictive performance.
- A lower-level `simulate_custom()` interface for user-defined data generators,
  model-fitting functions, and performance metrics.
- Getting-started and custom-workflow documentation on the package website.
- Experimental machine-learning options via regularised regression, random
  forest, and XGBoost. These are available in `0.5.0` but have not yet
  undergone the package's main validation study.

## Install

```r
# install.packages("remotes")
remotes::install_github("pmsims-package/pmsims", ref = "v0.5.0")
```

`0.5.0` is available from GitHub and is not yet a CRAN release.
