# pmsims 0.5.0

## What pmsims is

`pmsims` is an R package for simulation-based minimum sample size estimation
for prediction modelling. It helps users quantify how much data are needed to
develop prediction models that meet a target level of performance under
repeated sampling, rather than relying only on simple rules of thumb.

## Core functionality

- Wrapper functions for binary, continuous, and survival outcomes:
  `simulate_binary()`, `simulate_continuous()`, and `simulate_survival()`.
- A simulation-based learning-curve workflow that combines data generation,
  model fitting, and performance evaluation to estimate the minimum required
  sample size.
- Support for both mean-based and assurance-based criteria, including study
  designs that target acceptable performance with high probability.

## Flexible modelling and custom simulation

- A higher-flexibility `simulate_custom()` interface for custom data,
  modelling, and metric functions.
- Built-in support for standard regression models across outcome types.
- A model-agnostic design that separates data generation, model fitting, and
  performance evaluation.

## Getting started and documentation

- A getting-started vignette introducing the main wrapper workflows and core
  simulation inputs.
- README examples and package documentation intended to support both first-time
  users and more customised simulation studies.

## Experimental machine-learning support

- Machine-learning model options are available for the wrapper functions via
  regularised regression, random forest, and XGBoost.
- These machine-learning options are explicitly labelled experimental in the
  documentation.
- Experimental here means that these methods have not yet undergone the
  package's main validation study, so they should be treated as provisional in
  `0.5.0`.

## Installation

Install `pmsims` from GitHub:

```r
# install.packages("remotes")
remotes::install_github("pmsims-package/pmsims")
```

Version `0.5.0` is available from GitHub; the package is not yet released on
CRAN.
