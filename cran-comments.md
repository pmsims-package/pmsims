## \dontrun{} in examples

> \dontrun{} should only be used if the example really cannot be executed
> [...] Please unwrap the examples if they are executable in < 5 sec, or
> replace \dontrun{} with \donttest{}.

The four simulation examples now use `\donttest{}`. Each example runs a
sample size search targeting a calibration slope of 0.9 with 80% assurance,
1,000 simulation replications and 30,000 test observations. The examples use
simpler models other settings to keep runtime manageable while avoiding toy examples.

In the updated `simulate_custom()` example, the data, model and metric
functions are defined before the `\donttest{}` block. Only the simulation
search and result display are inside it. The generated `.Rd` files have
been updated accordingly.
There are no remaining `\dontrun{}` sections in the package documentation.

The vignette shows a larger, more realistic search than the examples can run.
Those results are
computed in advance and now ship as package data (`binary_example`,
`continuous_example`, `survival_example` and `custom_example`, documented
together under `?precomputed` and generated by
`data-raw/precomputed-examples.R`).

The complete local `R CMD check --as-cran --timings` took 279 seconds
(4 minutes 39 seconds), including 236 seconds for the `\donttest{}` examples.

## Console output (print()/cat())

> You write information messages to the console that cannot be easily
> suppressed. [...] -> R/engines.R; R/model_generators.R; R/simulate_custom.R;
> R/start_values.R

This has been fixed. The four progress messages written with `cat()` during a run (three in
`R/engines.R`, one in `R/simulate_custom.R`) now use `cli::cli_alert_info()`.
They are signalled as conditions on `stderr` and can be silenced with
`suppressMessages()`, consistent with the rest of the package.

## installed.packages()

> You are using installed.packages() in your code. [...] -> in your tests

This has been fixed. The single use, in `tests/testthat/test-model_generators.R`, now checks
each optional package with `requireNamespace(..., quietly = TRUE)`. The
corresponding `@importFrom utils installed.packages` has been dropped from
`NAMESPACE`. There are no remaining uses anywhere in the package.

## NOTEs from the earlier pre-test

The pre-test for the initial submission reported two NOTEs.

The first flagged possibly misspelled words in DESCRIPTION: "Olaniran",
"Shamsutdinova", "et", "al" and "generalisable". These are the surnames of
authors of the two cited papers, the standard abbreviation "et al.", and the
British spelling of "generalisable", which is used consistently throughout the
package. We believe no change is needed.

The second flagged the non-standard top-level directory 'scripts'. This
contained a helper script used when building the pkgdown site and should not
have been included in the tarball. It is now listed in .Rbuildignore.
